## Automated Exam Timetable & Invigilation Planner | UiPath RPA

Developed a Robotic Process Automation (RPA) solution using UiPath Studio and Microsoft Excel to simplify examination scheduling and invigilation management.

### Key Features
- Automated examination timetable generation using structured Excel data.
- Room allocation based on available room information.
- Faculty invigilation schedule generation.
- Scheduling conflict checks for students and faculty.
- Automated Excel output generation for examination and invigilation schedules.

### Technologies Used
UiPath Studio | Robotic Process Automation (RPA) | Microsoft Excel | VB.NET Expressions

### Objective
To reduce manual effort in examination administration, improve scheduling consistency, and simplify timetable and invigilation management.
